{# ---------- Director de Producción y testigos ---------- #}
El conteo de cada área lleva 3 firmas: el manager que lo carga (pestaña Accesos), el Director de Producción y un testigo de esta lista (lo elige el manager al enviar). Al Director y al testigo les llega un aviso por Cliq para firmar o rechazar con una observación. Con las 3 firmas el conteo queda en firme y se guarda el PDF del reporte en la carpeta de WorkDrive. Solo el Director de Producción o un administrador pueden anular las firmas para que el manager corrija y se vuelva a firmar. Se puede enviar en cualquier momento y las cantidades aceptan decimales (ej. 12.5).
